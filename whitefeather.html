软件简介

白羽（White Feather）是一门面向中文使用者的编程语言，也是一套开箱即用的桌面编程环境。变量、循环、条件、函数这些概念在这里统统换成了中文关键字，写代码更接近写一段通顺的中文句子。

它不只是一个解释器：配套的编辑器用原生 Win32 / C++ 渲染，文字清晰不发虚，支持深色与浅色主题切换、语法高亮、行号栏和彩色控制台。写完按 F5 直接运行，Shift+F5 随时中断，结果实时显示在下方控制台里。

安装包为单文件分发，已内置运行所需的全部组件，装完即用，不需要你再单独配置 Python 环境。

系统要求

  • 操作系统：Windows 10 / 11（64 位）
  • 磁盘空间：约 8 MB（安装包本身 3.14 MB）
  • 运行环境：无需预先安装 Python，也无需单独安装 VC++ 运行库——安装包已自带
  • 权限：默认装到当前用户目录，全程不需要管理员权限，不会弹出 UAC
  • 网络：软件本身无需联网即可使用
  • 提示：首次运行时若出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可（安装包使用自签名证书）
